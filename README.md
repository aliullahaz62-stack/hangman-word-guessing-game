# Hangman Word Guessing Game

## Project Description
This is a simple Hangman game developed in Python as part of my Datheon internship task.

The player guesses a hidden English word one letter at a time. The game allows a maximum of six incorrect guesses.

## Features
- Random English word selection from a text file.
- Maximum of six incorrect guesses.
- ASCII Hangman drawing.
- Displays correctly guessed letters and hidden letters.
- Prevents repeated guesses from causing a penalty.
- Displays win and lose messages.
- Validates user input.

## Requirements
- Python 3
- `google-10000-english-no-swears.txt`

## How to Run
1. Keep `hangman.py` and `google-10000-english-no-swears.txt` in the same folder.
2. Open a terminal in that folder.
3. Run:

   `python hangman.py`
